# Crie uma página com os campos abaixo.

- Nome completo

- e-mail

- idade

- Para qual matéria você está se candidatando para lecionar: Matematica, Portugues, Biologia, Ciencias, História, Geografia e Artes.

- Nivel de escolaridade: Ensino superior completo, Cursando mestrado, Mestrado completo, Cursando doutorado, Doutorado completo

- Descrisção de si mesmo

## REGRAS

- O Form deve ter ID e nome de "form"

- Os nomes dos campos devem ser respectivamente: nome, e-mail, idade, assunto, turnos disponiveis, escolaridade, descrição.

-O campo com as opções de materias deve ter um iD também.

Código precisa ser semantico e com acessibilidade.
